Mexer com IA e fazer bons prompts

  
A IA responde ao que você pede. Quanto mais claro o pedido, melhor o resultado. Use a fórmula P-C-T-F-R sempre que for pedir algo.

  

    
PapelQuem a IA deve ser

    
ContextoSituação e público

    
TarefaUma coisa bem definida

    
FormatoComo quer receber

    
RestriçõesLimites e o que evitar

  

  

    
Hábitos que melhoram tudo
    
      
  • Peça uma coisa por vez e evolua em etapas.
    • 
      
  • Dê exemplos do que você gosta e do que não gosta.
    • 
      
  • Se o resultado vier ruim, diga o que mudar em vez de recomeçar.
    • 
      
  • Peça para a IA explicar o que fez. Assim você aprende.
    • 
    

    
Erros comuns
    
      
  • Pedido vago, como “faça um site bonito”.
    • 
      
  • Vários pedidos misturados numa mensagem só.
    • 
      
  • Confiar sem testar: sempre rode e confira o resultado.
    • 
      
  • Colar senhas, chaves de API ou dados pessoais no chat.
    • 
    

  






  
Programar com IA

  
Você descreve o que quer, a IA escreve o código e você revisa. Existem três jeitos de trabalhar, do mais simples ao mais profissional.

  

    
Iniciante
No chat
Peça o código, copie para um arquivo e teste. Ótimo para os primeiros projetos e para tirar dúvidas.
  • Peça o código completo, não só trechos.
  • Cole o erro inteiro quando algo falhar.

    
Intermediário
No editor (VS Code)
Abra a pasta do projeto no VS Code e use a IA ao lado dos seus arquivos, com o contexto do projeto.
  • Peça mudanças pequenas e revise cada uma.
  • Use o Git para poder desfazer.

    
Profissional
No terminal (Claude Code)
O Claude Code lê seu projeto, cria e edita arquivos e roda comandos por você, sempre pedindo permissão.
  • Entre na pasta e digite claude.
  • Descreva o objetivo, depois revise o que ele fez.

    
Seu ciclo de trabalho
Todo projeto segue o mesmo ritmo.
  • Descreva o que quer.
  • Rode e teste.
  • Corrija com um novo pedido.
  • Salve com um commit.

  






  
Skills, plugins e conectores

  
São extensões que ensinam o Claude a fazer tarefas específicas ou a falar com outras ferramentas. Cada uma tem um papel diferente.

  

    
Skill
Uma pasta de instruções que ensina um jeito de trabalhar, como seguir o padrão de código do seu time ou criar slides. O Claude usa quando a tarefa combina.

    
Plugin
Um pacote que reúne skills, comandos e conexões. Instalar um plugin é o jeito mais rápido de ganhar vários recursos de uma vez.

    
Conector (MCP)
Liga o Claude a serviços como GitHub, Notion ou Google Drive, para ele ler e agir onde seu trabalho já está.

    
Plugins para começar no Claude Code
  • Superpowers: plano, spec e testes antes de codar.
  • Context7: documentação atualizada das bibliotecas.
  • code-review: revisão automática das mudanças.
  • GitHub: issues e PRs dentro da sessão.

  

  
Instalar um plugin no Claude Code leva dois comandos:

  
/plugin marketplace add obra/superpowers-marketplace

  
/plugin install superpowers@superpowers-marketplace

  
Instale poucos plugins. Cada um ocupa espaço na memória de trabalho da IA, então comece com três ou quatro.






  
Mexer com apps: VS Code, Git e GitHub

  
Três ferramentas que quase todo programador usa. O VS Code edita, o Git guarda o histórico e o GitHub guarda tudo na nuvem.

  

    
VS Code
O editor onde você abre e lê seus arquivos.
  • Instale em code.visualstudio.com.
  • Use Arquivo → Abrir Pasta para abrir o projeto.
  • O terminal fica em Terminal → Novo Terminal.
  • Instale a extensão do Claude Code para usá-lo ao lado do código.

    
Git
Guarda versões do seu projeto, como pontos de salvamento de um jogo.
  • commit: salva uma versão com uma mensagem.
  • branch: uma linha paralela para testar sem risco.
  • push: envia suas versões para o GitHub.

    
GitHub
Site onde seu código fica guardado, compartilhável e à vista no seu portfólio.
  • Crie uma conta em github.com.
  • Repositório: a pasta do projeto na nuvem.
  • Issue: uma tarefa ou um problema anotado.
  • Pull request: um pedido para juntar mudanças.

    
Primeira configuração do Git
git config --global user.name "Seu Nome"
git config --global user.email "voce@email.com"
Faça isso uma vez só por computador.

  






  
Mexer com sites: GitHub e Vercel

  
Seu site precisa de um endereço na internet. O GitHub guarda o código e a Vercel publica, gerando um link .vercel.app grátis.

  

    
GitHub
Guarda e versiona o código. Também permite publicar páginas simples pelo GitHub Pages.

    
Vercel
Pega o código do GitHub e coloca no ar. Cada vez que você envia uma mudança, o site atualiza sozinho.

  






  
Roteiro: do zero ao site no ar

  
Siga na ordem. Em cada passo, se algo der erro, copie a mensagem inteira e peça ajuda à IA.

  
    
    
  1. Crie o projeto com a IA
    Use o prompt que você montou lá em cima e salve o resultado como index.html numa pasta nova.
    2. 
    
  2. Abra no VS Code e teste
    Abra a pasta e dê dois cliques no index.html para ver no navegador. Peça ajustes à IA até gostar.
    3. 
    
  3. Guarde a versão com Git
    No terminal do VS Code, dentro da pasta:
    
      
    git init
    
      
    git add .
    
      
    git commit -m "primeira versão"
    4. 
    
  4. Envie para o GitHub
    Crie um repositório vazio em github.com e copie o endereço dele. Depois rode, trocando pelo seu endereço:
    
      
    git branch -M main
    
      
    git remote add origin https://github.com/SEU-USUARIO/meu-site.git
    
      
    git push -u origin main
    5. 
    
  5. Publique na Vercel
    Entre em vercel.com com sua conta do GitHub, clique em Add New → Project, escolha o repositório e clique em Deploy. Em cerca de um minuto você recebe um link .vercel.app para compartilhar.
    6. 
    
  6. Atualize quando quiser
    Peça a mudança à IA, teste e envie. A Vercel publica a nova versão sozinha:
    
      
    git add . && git commit -m "atualização" && git push
    7. 
  






  
Biblioteca de prompts prontos

  
Copie, troque o que estiver em letras maiúsculas pelo seu caso e envie para a IA.

  

    
Criar um site
Você é um designer de sites experiente. Crie a página inicial de um site para MEU NEGÓCIO, com público de TIPO DE CLIENTE. Entregue um único arquivo index.html com HTML e CSS, bom no celular, tom simples e acolhedor.

    
Criar um jogo
Crie um jogo simples em um único arquivo index.html onde TIPO DE PERSONAGEM desvia de obstáculos. A velocidade aumenta a cada 10 pontos. Mostre a pontuação e um botão de reiniciar.

    
Corrigir um erro
Estou fazendo O QUE VOCÊ ESTAVA FAZENDO e apareceu este erro: COLE A MENSAGEM INTEIRA. Explique a causa em linguagem simples e mostre a correção passo a passo.

    
Entender um código
Explique este código como se eu fosse iniciante, parte por parte, e diga o que cada trecho faz: COLE O CÓDIGO.

    
Melhorar um texto de anúncio
Você é redator de anúncios. Reescreva este texto para PÚBLICO em até 40 palavras, com um título forte e uma chamada para ação clara. Entregue 3 versões diferentes.

    
Estudar um assunto
Seja meu professor de ASSUNTO. Explique em 5 passos curtos, com um exemplo prático em cada um, e depois me faça 3 perguntas para eu testar o que aprendi.

  






  
Perguntas frequentes

  

  
Preciso saber programar antes?
Não. Você aprende fazendo, e a IA explica cada parte. Só peça sempre que ela explique o que escreveu.

  
É seguro publicar código no GitHub?
Sim, desde que você nunca envie senhas, chaves de API ou dados pessoais. Se guardar chaves em um arquivo .env, peça à IA para colocá-lo no .gitignore.

  
Deu erro. O que eu faço?
Copie a mensagem inteira, cole na IA e diga o que você estava fazendo. Quase sempre ela indica a correção.

  
Preciso pagar pela Vercel ou pelo GitHub?
Os planos gratuitos já bastam para projetos de estudo. Confira os limites atuais nos sites oficiais.
